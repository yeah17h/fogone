# 005 第一個支援的外語

- 日期：2026-11-25
- 狀態：定案（Aya 確認）

## 決定
生詞標記與單字本的第一個語言是**英文**，日文第二、韓文第三。雙語翻譯本身仍支援 legacy 已有的語言。

## 理由
- 英文斷詞用瀏覽器內建 `Intl.Segmenter`（0 KB），詞形還原自寫規則約 10–15 KB。
- 日文要精準還原原型需 12.5–17 MB 字典；韓文需 22–89 MB。
- Chrome 內建 `en→zh-Hant` 翻譯在 legacy 實測最穩定。

## 後果
日文之後要做時，字典採「需要時才下載到 IndexedDB」，不塞進安裝包。
