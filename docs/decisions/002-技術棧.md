# 002 技術棧

- 日期：2026-11-25
- 狀態：定案（Aya 確認）

## 決定
| 層級 | 選擇 |
|---|---|
| 擴充建置框架 | WXT 0.21.x（擴充功能開發框架，MIT） |
| 語言 | TypeScript 嚴格模式 |
| 網頁注入層（content script、lib/） | 零框架、純 DOM |
| 擴充自有頁面（popup、PDF 檢視器、單字本、測驗頁） | React 19 |
| 本機資料庫封裝 | Dexie 4.x（Apache-2.0），只在背景程式與自有頁面使用 |
| 測試 | Vitest（單元測試）＋ Playwright 透過 CDP 接真 Chrome（沿用 legacy/scripts/chrome.mjs） |
| 預設翻譯引擎 | Chrome 內建 Translator API（本機翻譯，文字不出裝置） |

## 理由
- 跟 legacy 一致，風險最低；read-frog、FluentRead 也證實 WXT 0.21 可行。
- 選 Dexie 不選 idb：單字本需要「今天到期要複習的字」這類多索引查詢與 schema 升級，Dexie 寫起來簡單得多；多出的約 76 KB 只在背景程式與自有頁面載入，不影響網頁效能。

## 不採用
- Dexie Cloud（Dexie 官方的付費雲端同步服務）：資料會經過第三方伺服器且要付費，與隱私定位衝突。同步方案見 004。
