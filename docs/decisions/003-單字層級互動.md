# 003 單字層級互動

- 日期：2026-11-25
- 狀態：定案（Aya 確認）

## 決定
1. **生詞標記**：CSS Custom Highlight API（瀏覽器只在畫面上繪製標記，不修改網頁結構）。用 `StaticRange` 組成 `Highlight`，名稱一律加 `yi-` 前綴，樣式用 `::highlight(yi-...)`。
2. **點擊已標記生詞**：Chrome 140+ 用 `CSS.highlights.highlightsFromPoint()`；較舊版本退回 `caretPositionFromPoint` 比對範圍。
3. **查任意未標記單字**：用不跟網站衝突的明確手勢（`Alt+點擊`，或選字後出現的小按鈕），以 `caretPositionFromPoint` + `Intl.Segmenter` 取詞。不攔截一般點擊，不碰連結、按鈕、輸入框。
4. **查詞卡片**：整頁只掛一個 `<x-yi-card>`（Shadow DOM，純 DOM 渲染，不用 React），掛在 `document.documentElement`，絕不搬動頁面原有節點。
5. **Shadow DOM**：遍歷 open `shadowRoot`，並把同一份樣式表加進 `shadowRoot.adoptedStyleSheets`。

## 理由
完全不修改網頁原文節點，守住鐵律「網頁注入零框架」與「零頁面破壞」；關閉功能時 `CSS.highlights.delete()` 即可完全還原。

## 不採用
用 `<span>`／`<mark>` 包裹原文：會破壞 React/Vue 網站、觸發版面重排，違反零破壞。

## 範圍外（之後再議）
YouTube 字幕上的單字點選：字幕覆蓋層目前是 `pointer-events: none`，第一階段只做翻譯。
