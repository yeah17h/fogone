## 詳細說明

（慣用上限 16,000 字元，實際遠低於）

```
【你的文字會去哪裡】

預設（本地引擎）：哪裡都不去。翻譯由 Chrome 內建的裝置端模型完成，文字從未離開你的瀏覽器。

BYOK（尚未推出）：從你的瀏覽器直接連到你自己設定的服務供應商，用你自己的金鑰。

免費與預設功能一律在你的裝置上、或直連你自選的服務完成，永不經過我們的伺服器。
BYOK 模式下資料到的是你指定的那家供應商（那是你選的、你付費的、你隨時可以換掉的），
中間不多停一站。

【零遙測】

沒有使用統計、沒有錯誤回報、沒有遠端 log。連「有多少人在用」我們都不知道。
擴充內顯示的統計數字（翻了幾段、呼叫幾次引擎、快取命中幾次）只存在你的分頁記憶體裡，
關掉分頁就消失，只有你看得到——那是給你除錯用的，不是給我們的。

安裝時你會看到：這個擴充要求的權限是空的。

【功能】

・整頁雙語對照：譯文加在原文下方，不覆蓋、不取代原文，隨時可一鍵移除
・只翻該翻的：導覽列、側欄、頁尾的 UI 標籤不翻，避免版面被撐開
・YouTube 字幕即時翻譯：包含自動生成的 CC 字幕，原文與譯文同時可見
・已經是中文的內容自動跳過
・往下捲動時自動接續翻譯新出現的內容
・翻過的內容會記在分頁記憶體裡，同一段不會重複送進引擎

【需求】

・桌面版 Chrome 138 以上（本地翻譯 API 只存在於此）
・Edge、Brave、Arc 等其他 Chromium 系瀏覽器目前沒有這個 API，不支援
・首次使用需在擴充視窗點一次「啟用本地翻譯」下載語言包（下載後全程離線運作）

【開源】

原始碼：TBD（repo 連結待補）
授權：AGPL-3.0

隱私承諾不該只是一段文字。程式碼是公開的，上面那些說法你可以自己驗證。
```
