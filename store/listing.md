```
【你的文字會去哪裡】

預設（本地引擎）：哪裡都不去。翻譯由 Chrome 內建的裝置端模型完成，文字從未離開你的瀏覽器。

BYOK（尚未推出）：從你的瀏覽器直接連到你自己設定的服務供應商，用你自己的金鑰。

免費與預設功能一律在你的裝置上、或直連你自選的服務完成，永不經過我們的伺服器。
BYOK 模式下資料到的是你指定的那家供應商（那是你選的、你付費的、你隨時可以換掉的），
中間不多停一站。

【零遙測】

沒有使用統計、沒有錯誤回報、沒有遠端 log。連「有多少人在用」我們都不知道。
擴充內顯示的統計數字（翻了幾段、呼叫幾次引擎、快取命中幾次）只存在你的分頁記憶體裡，
關掉分頁就消失，只有你看得到——那是給你除錯用的，不是給我們的。

【權限】

除了翻譯所必需的「讀取你正在瀏覽的網頁內容」之外，不要求任何其他權限
——不讀書籤、歷史、分頁、下載，沒有背景權限。

翻譯工具無法事先知道你想在哪個網站閱讀外文，所以讀取範圍涵蓋你造訪的網站，
安裝時會顯示對應的警告。能縮小的是「除此之外一概不要」，這一點我們做到底：
沒有任何背景權限，程式碼公開可查。

【功能】

・整頁雙語對照：譯文加在原文下方，不覆蓋、不取代原文，隨時可一鍵移除
・只翻該翻的：導覽列、側欄、頁尾的 UI 標籤不翻，避免版面被撐開
・YouTube 字幕即時翻譯：包含自動生成的 CC 字幕，原文與譯文同時可見
・已經是中文的內容自動跳過
・往下捲動時自動接續翻譯新出現的內容
・翻過的內容會記在分頁記憶體裡，同一段不會重複送進引擎

【需求】

・桌面版 Chrome 138 以上（本地翻譯 API 只存在於此）
・Edge、Brave、Arc 等其他 Chromium 系瀏覽器目前沒有這個 API，不支援
・首次使用需在擴充視窗點一次「啟用本地翻譯」下載語言包（下載後全程離線運作）
```

### 標註要求（2026-09-03 補正）

原本只寫一句「內容來自 MDN 與維基百科（CC BY-SA）」，**那不符合這兩個授權實際要求的標註**。
MDN 明文要求：文件標題、指向該頁的超連結、修改說明，以及署名「Mozilla Contributors」；
CC BY-SA 4.0 同樣要求署名、授權連結與變更聲明。詳細說明裡的
【螢幕擷取畫面的內容來源】區塊已依此改寫，換素材時要一起改。

**截圖都是經過修改的**（疊上我們產生的譯文、加上標題橫幅），所以「經修改」這句不能省。

### 換素材時的兩條規矩

1. 換 YouTube 影片**一定要實際打開影片頁確認授權欄位寫的是創用 CC**——
   搜尋結果的 CC 篩選器會撈到轉載頻道自行標 CC 的內容，那不算數
   （實測踩過：搜尋結果前排有兩支是第三方轉載的 MIT 課程）。
2. 授權會變。上傳者隨時可以把 CC 改回標準授權，頁面也可能下架。
   送審前重驗一次，別依賴這份表格上次查證的結果。

### 未決：ShareAlike 對商店素材的效力（需要你判斷）

MDN 與維基百科都是 **BY-SA**（相同方式分享）。截圖是「重製」還是「改作」在法律上有模糊地帶：
若被視為改作，ShareAlike 理論上會要求該衍生素材也以 CC BY-SA 釋出——
而商店素材通常不會這樣標。實務上翻譯類擴充普遍這樣用，風險低，但**這是判斷不是事實**。

要完全沒有這層模糊，唯一乾淨的做法是把兩張截圖換成
**自有頁面或公有領域／CC0 來源**（YouTube 那張是 CC BY，沒有 SA，不受影響）。
成本是重跑一次 `node scripts/store-assets.mjs`。要不要做由你決定。
