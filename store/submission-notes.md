# Chrome 線上應用程式商店 — 提交說明

給審查用的回答草稿。後台問題的實際措辭可能與此不同，以下是各題的**事實內容**，
填寫時照後台的問法調整表述即可，但**事實不要改**。

---

## 單一用途聲明

> 後台會要求用一句話說明擴充的單一用途。

```
把網頁內容與 YouTube 字幕翻譯成使用者的語言，並與原文並列顯示。
```

補充說明（若後台允許展開）：

```
本擴充只做一件事：雙語翻譯。網頁內文與 YouTube 的 CC 字幕使用同一套翻譯管線，
譯文加在原文旁邊、不取代原文。沒有其他附帶功能。
```

---

## 權限說明

**`permissions`：空陣列。** 本擴充不要求任何 Chrome 權限 API。

| 項目 | 內容 | 為什麼需要 |
|---|---|---|
| `permissions` | `[]` | 不需要。翻譯用的是網頁平台本身的 `Translator` API，不是 Chrome 擴充權限。 |
| `host_permissions` | 未宣告 | 同上。 |
| content script `matches` | `<all_urls>` | 使用者可能在任何網站上想要雙語對照，無法事先列舉網域。 |

content script 的用途，一句話：

```
讀取目前頁面的文字、翻譯後把譯文以新節點加在原文旁邊；不修改原有內容、
不讀取或送出表單與輸入欄位、不攔截使用者事件。
```

content script 只在使用者主動點擊擴充圖示並選擇「雙語翻譯此頁」後才開始工作。
在那之前它只是在頁面裡等待訊息，不讀取也不處理任何內容。

## 資料使用揭露問卷

後台會逐項要求勾選是否收集。**全部皆為「否」。**

| 問卷項目 | 答案 |
|---|---|
| 個人身分資訊（姓名、地址、email、年齡、身分證字號等） | 否 |
| 健康資訊 | 否 |
| 財務與付款資訊 | 否 |
| 驗證資訊（密碼、憑證、安全性問題等） | 否 |
| 個人通訊內容（email、簡訊、聊天訊息等） | 否 |
| 位置資訊 | 否 |
| 網頁瀏覽紀錄 | 否 |
| 使用者活動（點擊、滑鼠位置、捲動、按鍵記錄等） | 否 |
| 網站內容（文字、圖片、聲音、影片、超連結等） | 否 |

**「網站內容」該不該勾「是」——這一題最容易答錯，理由寫在這裡以免下次動搖：**

本擴充確實會**讀取**網頁文字才能翻譯，但問卷問的是「**收集**」（collect），
定義為傳輸到擴充之外。本擴充在預設模式下不傳輸任何內容：翻譯由 Chrome 內建的
裝置端模型完成，文字從未離開瀏覽器。因此答「否」。

BYOK 模式上線後這一題要重新評估：屆時文字會依使用者自己的設定送往使用者自己選擇的
供應商。**送出去之前必須先確認揭露內容是否需要更新，不要沿用這份答案。**

三項聲明（後台勾選）：

- 不將使用者資料販售或轉移給第三方（用於核准用途以外）：**確認**
- 不將使用者資料用於或轉移供與擴充單一用途無關的目的：**確認**
- 不將使用者資料用於或轉移以判定信用狀況或提供貸款：**確認**

## 其他可能被問到的

**為什麼需要 `<all_urls>`？**
無法預先知道使用者想在哪個網站閱讀外文。這是通用型翻譯工具的必然範圍，
與其他同類擴充一致。擴充本身沒有要求任何 Chrome 權限 API 可以佐證範圍沒有被濫用。

**遠端程式碼：無。** 所有程式碼都包含在套件內，不下載、不執行任何遠端腳本。

**混淆處理：無。** 建置產物是一般的 minify，未做任何混淆。原始碼公開可對照。
